# Test Case Template

| Field | Description |
|---|---|
| **ID del caso** | TC-001 |
| **Título** | Brief description of what's being tested |
| **Módulo / Función** | e.g. Login, Search, Profile |
| **Precondiciones** | What must be true before running the test |
| **Pasos** | 1. \n2. \n3. |
| **Datos de prueba** | Specific values used |
| **Resultado esperado** | What should happen if everything works |
| **Resultado actual** | What actually happened |
| **Estado** | Passed / Failed / Blocked |
| **Severidad / Prioridad** | High / Medium / Low |

# Example — Instagram

| Field | Value |
|---|---|
| **ID del caso** | TC-002 |
| **Título** | Verify search field shows results when typing a valid term |
| **Módulo / Función** | Search (Explore) |
| **Precondiciones** | User must be logged into the app |
| **Pasos** | 1. Open Instagram<br>2. Tap the search icon<br>3. Type "cats" in the search field |
| **Datos de prueba** | Search text: "cats" |
| **Resultado esperado** | App shows a list of profiles, hashtags, or posts related to "cats" |
| **Resultado actual** | App correctly showed related results |
| **Estado** | Passed |
| **Severidad / Prioridad** | Medium |
